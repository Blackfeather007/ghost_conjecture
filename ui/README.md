# 数学条目依赖关系管理器

这是一个用于管理从arXiv论文中提取的数学条目的Web界面，支持编辑条目内容、添加注释、管理依赖关系，并导出修改后的JSON文件。

## 功能特性

- 📁 **文件加载**: 选择并加载JSON文件
- 📋 **条目浏览**: 查看所有提取的数学条目（定义、定理、引理等）
- 🔍 **筛选搜索**: 按类型、章节筛选，支持关键词搜索
- ✏️ **内容编辑**: 编辑条目的内容和证明
- 💬 **注释功能**: 为条目添加注释
- 🔗 **依赖管理**: 为条目添加和删除依赖关系
- 📐 **LaTeX渲染**: 实时预览LaTeX数学公式（使用KaTeX）
- 💾 **导出功能**: 将修改后的数据导出为JSON文件

## 使用方法

1. **打开界面**: 在浏览器中打开 `index.html` 文件
   ```bash
   # 方法1: 直接双击打开
   # 方法2: 使用Python简单服务器
   cd ui
   python3 -m http.server 8000
   # 然后在浏览器访问 http://localhost:8000
   ```

2. **加载JSON文件**: 点击"选择JSON文件"按钮，选择 `output/` 目录中的JSON文件

3. **浏览条目**: 
   - 在左侧列表中查看所有条目
   - 使用筛选器按类型或章节筛选
   - 使用搜索框搜索关键词

4. **编辑条目**:
   - 点击列表中的条目查看详情
   - 编辑内容或证明（支持LaTeX）
   - 添加注释
   - 管理依赖关系

5. **添加依赖关系**:
   - 在详情面板的"依赖关系"部分
   - 从下拉菜单中选择要添加的依赖条目
   - 点击"添加依赖"按钮
   - 可以点击"删除"按钮移除依赖

6. **保存和导出**:
   - 点击"保存修改"按钮保存当前条目的更改
   - 点击"导出JSON"按钮导出修改后的完整数据

## 数据格式

修改后的JSON文件会在原有结构基础上添加两个新字段：

```json
{
  "type": "definition",
  "label": "E:bar rho",
  "content": "...",
  "section": "Introduction",
  "subsection": null,
  "line_number": 373,
  "proof": null,
  "dependencies": [0, 5, 12],  // 新增：依赖的条目索引数组
  "comment": "这个定义依赖于前面的概念"  // 新增：用户注释
}
```

## LaTeX支持

界面使用KaTeX库渲染LaTeX数学公式，支持：

- 行内公式: `$...$` 或 `\(...\)`
- 块级公式: `$$...$$` 或 `\[...\]`
- 环境: `equation`, `align`, `alignat`, `gather`, `multline` 等

公式会在内容预览区域实时渲染。

## 注意事项

- 所有修改都在浏览器本地进行，不会自动保存
- 请定期使用"导出JSON"功能保存您的工作
- 依赖关系使用条目在数组中的索引，导出后索引保持不变
- LaTeX渲染需要网络连接（使用CDN），如需离线使用，请下载KaTeX库到本地
